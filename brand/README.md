# DRAP Concord: logo

Logo vetorizada a partir da arte original, com fundo transparente e na cor primária da plataforma.

| Arquivo | Cor | Uso |
| --- | --- | --- |
| `logo.svg` | Azul-petróleo `#1F4E5A` (primária) | Fundos claros (creme `#FBF7F2`, areia `#F3EBDF`, branco) |
| `logo-light.svg` | Creme `#FBF7F2` | Fundos escuros (modo escuro, fundo primário) |
| `logo-512.png`, `logo-1024.png` | `#1F4E5A` | Versões raster com fundo transparente |
| `logo-light-512.png`, `logo-light-1024.png` | `#FBF7F2` | Versões raster com fundo transparente |

Prefira o SVG sempre que possível. Os PNGs servem para lugares que não aceitam SVG (e-mail, redes sociais etc.).

Contraste (WCAG): `#1F4E5A` sobre `#FBF7F2` ≈ 8,6:1.
